# Quick Test Reference Card

## 🚀 Quick Commands

```bash
npm install              # Install dependencies
npm test                # Run all tests
npm run test:watch      # Watch mode
npm run test:coverage   # With coverage
npm run test:e2e        # E2E tests
```
