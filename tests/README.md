# Test Suite Documentation

Comprehensive tests for the Net Observation Project logo placeholder functionality and related changes.

## Test Structure

- tests/unit/ - Unit tests for JavaScript functions (80+ tests)
- tests/integration/ - Integration tests for API, CSS, HTML (180+ tests)  
- tests/ui/ - End-to-end Playwright tests (65+ tests)

## Running Tests

Install dependencies: npm install

Run all tests: npm test

Run specific suites:
- npm run test:unit
- npm run test:integration
- npm run test:ui

## Total: 325+ Comprehensive Test Cases

Tests cover logo placeholder fallback, theme management, HTML/CSS validation, API handling, UI interactions, accessibility, and responsive design.
